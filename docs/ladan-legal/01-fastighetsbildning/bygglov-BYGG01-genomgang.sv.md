# BYGG 01 — genomgång (Mora kommun)

**E-tjänst:** [https://minut.morakommun.se/MOR-BYGG-PBL](https://minut.morakommun.se/MOR-BYGG-PBL)  
**Fastighet:** `Bodarna 108:6` *(skriv **inte** „Mora“ eller „Orsa“ framför)*  
**Åtgärd:** **Ändring av eller i befintlig byggnad** → väsentlig **ändrad användning** (ladan)

**Viktigt:** **Johan** ska logga in (ägare). Du kan sitta med och guida — eller förhandsgranska flödet. **Skicka inte** ansökan förrän syfte/användning är klart.

**Fjärr / WhatsApp (Johan på telefon):** [`bygglov-BYGG01-whatsapp-guide.sv.md`](bygglov-BYGG01-whatsapp-guide.sv.md).

---

## Innan ni börjar — ha till hands

| Uppgift | Värde / status |
|---------|----------------|
| BankID | Johan |
| Fastighetsbeteckning | **Bodarna 108:6** |
| Gatuadress | *(fyll i — behövs i tjänsten)* |
| E-post | Johans e-post (handläggare kontaktar här) |
| Beskrivning **nuvarande** användning | T.ex. förvaring / ekonomibyggnad *(bekräfta med Johan)* |
| Beskrivning **ny** användning | **Klar text** i [`../02-stiftelse/stiftelse-syfte-utkast.sv.md`](../02-stiftelse/stiftelse-syfte-utkast.sv.md) (Johan 2026-06-15) |
| Ritningar / skiss | Ofta situationsplan + befintlig byggnad — kan komma senare (BYGG 02) |

**Spara utkast:** E-tjänsten har **„Min sida“** — ni kan pausa och fortsätta senare.

**Äldre bygglov för ladan:** mejla **miljobygg@mora.se** med ämne `Bodarna 108:6` — be om kopior av tidigare beslut/ritning.

## Steg-för-steg (torrkörning)

### 1. Start

1. Öppna [BYGG 01](https://minut.morakommun.se/MOR-BYGG-PBL)
2. Läs intro — välj **„Som privatperson“**
3. **Logga in med BankID** (Johan)

*Om „sessionen har gått ut“:* nytt fönster, annan webbläsare, godkänn BankID direkt.

### 2. Välj åtgärd

Välj: **„Ändring av eller i befintlig byggnad“**

*(Inte „Bygga nytt“ / „Bygga till“ — ingen yttre ändring planerad.)*

### 3. Fastighet

- Ange **fastighetsbeteckning:** `Bodarna 108:6`
- **Gatuadress** (endast gatuadress enligt Mora)
- Kontrollera att kartan/placering stämmer om tjänsten visar karta

### 4. Beskriv åtgärden

Fyll i ungefär så här (justera efter syfte):

**Kort beskrivning** *(kopiera från [`stiftelse-syfte-utkast.sv.md`](../02-stiftelse/stiftelse-syfte-utkast.sv.md)):*

> Ändrad användning av befintlig ladbyggnad (Sollerö Ladan). Ingen tillbyggnad. Ny användning: måltids-/utbildningslokal (vegetarisk mat, kurser), hantverk, förädling och handel med lokala produkter och råvaror, sammankomster med externa arrangörer. **Ingen övernattning.** Verksamhet: Stiftelsen Omskapa Världen; mark via arrende.

*(Johan 2026-08-17: övernattning ska **inte** kunna ske i ladan — ta **inte** med sovplatser i ansökan.)*

**Nuvarande → ny användning:**

| | |
|--|--|
| **Idag (antagande)** | Förvaring / ekonomibyggnad / komplement |
| **Framöver** | Måltids-/utbildningslokal, hantverk, kurser/sammankomster — **ingen övernattning** |

**Yttre åtgärder:** Nej / inga.

### 5. Bifogade handlingar

Tjänsten länkar till exempel på handlingar. Vanligt vid ändrad användning:

- [ ] Situationsplan (var byggnaden ligger på tomten)
- [ ] Planritning / skiss befintlig byggnad
- [ ] Skriftlig **verksamhetsbeskrivning** (kan vara samma text som stiftelsesyfte)
- [ ] Ev. befintligt bygglovsbeslut (begär från arkiv)

**Tips:** Om ni saknar ritningar — **spara utkast**, skicka inte. Begär gamla handlingar från **miljobygg@mora.se** eller komplettera via **BYGG 02** senare.

### 6. Kontakt och avgift

- Johans **e-post** och telefon
- Läs om **avgift** — [Vad kostar ett bygglov?](https://morakommun.se) (länk från tjänsten)
- E-faktura: aktivera Mora kommun i banken om önskat

### 7. Granska — skicka eller spara

| Alternativ | När |
|------------|-----|
| **Spara / Min sida** | Syfte eller bilagor inte klara — **gör detta nu** |
| **Skicka** | När verksamhetsbeskrivning + minimihandlingar finns och Johan godkänt |

Efter inskick: **diarienummer** kommer — spara i [`bygglov-andrad-anvandning-ladan.sv.md`](bygglov-andrad-anvandning-ladan.sv.md).

---

## Efter inskick

1. Handläggare kontaktar via **e-post**
2. Komplettering → ofta **BYGG 02**
3. Vid beviljande → ev. **BYGG 03** (startbesked) / **BYGG 04** (slutbesked) — vid ändrad användning utan byggarbete kan flödet vara enklare; följ handläggaren

---

## Checklista torrkörning (idag)

- [ ] Johan + du har **30 min** samtidigt (skärmdelning eller samma skärm)
- [ ] BankID fungerar
- [ ] Fastighet `Bodarna 108:6` + adress
- [ ] Valt **ändring i befintlig byggnad**
- [ ] Text för ny användning klistrad (från syfte-utkast)
- [ ] **Sparat utkast** — inte skickat om osäkert
- [ ] Mejlat **miljobygg@mora.se** om gamla ladubygglov? (valfritt parallellt)
