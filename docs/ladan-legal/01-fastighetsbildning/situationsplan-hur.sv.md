# Situationsplan — hur ni gör den (Sollerö Ladan)

Ni behöver **två saker som liknar varandra** men inte är samma papper.

| | **BYGG 01 (kommunen)** | **Arrende / G1 (jurist)** |
|--|------------------------|---------------------------|
| **Syfte** | Visa **var ladan står** på tomten | Visa **vilken mark** stiftelsen arrenderar |
| **Måste imorgon?** | Bra att ha — **saknas den: spara utkast**, komplettera via BYGG 02 | **Nej** — kan göras efter BYGG 01 |
| **Vad som räcker först** | Fastighetskarta + lada inritad | Samma karta + **streckad arrendegräns** |

Johans **handskiss** ([`../misc/landskiss.jpeg`](../misc/landskiss.jpeg)) är bra som arbetsunderlag — **inte** tillräcklig som enda situationsplan mot kommun/jurist.

---

## Arrendegränsen som ska synas (G1)

Enligt Johan 2026-08-17:

```text
                    [bakom: bara fotavtryck]
     vänster:          ┌──────────────┐         höger:
     bara vägg         │    LADAN     │         bara vägg
                       │   (ingång)   │
                       └──────┬───────┘
                              │  framsida
                              │  hela vägen
                       ═══════╧═══════  VÄG
```

- **Framsida (långsida med ingång):** från yttervägg **ända till vägen**.  
- **Höger, vänster, bakom:** **endast** där ladan står.

---

## Enklaste sättet (rekommenderat)

### 1. Hämta karta från Lantmäteriet (BankID)

1. Öppna [Min karta](https://minkarta.lantmateriet.se) (eller Lantmäteriets **Min karta** / karttjänst med fastighetssök).  
2. Sök **Bodarna 108:6**, Mora.  
3. Zooma så **hela tomten + ladan + vägen** syns.  
4. **Skriv ut** (PDF eller papper) **eller** skärmdump i hög upplösning.

*Om Johan inte klarar det:* du gör kartuttaget; han behöver inte rita själv.*

### 2. Rita på kartan (penna eller i PDF)

På utskriften:

1. Ringa in **ladan**.  
2. Markera **vägen** vid framsidan.  
3. **Skugga/strecka** arrendeområdet: ladans yta + remsan mellan långsida och väg.  
4. Skriv i hörnet:

```text
Situationsplan — arrende Sollerö Ladan
Mora Bodarna 108:6
Stiftelsen Omskapa Världen
Framsida (ingång/långsida) till vägen.
Höger, vänster, bakom: endast byggnadens fotavtryck.
Datum: ________  Skiss: Johan / Peter
```

5. Foto eller skanna → spara som t.ex. `docs/ladan-legal/misc/situationsplan-arrende.jpg` (utan personnummer).

### 3. Mått (valfritt nu, bra före G1)

På plats: mät **avstånd långsida → vägkant** (meter). Skriv siffran på ritningen. Då kan arrendeytan räknas: ~210 m² (byggnad) + (27 m × avståndet till vägen).

Ni behöver **inte** anlita lantmätare för första skissen. G1 säger om inskrivning kräver finare karta.

---

## BYGG 01 imorgon

Om e-tjänsten **kräver** situationsplan och ni inte hunnit:

- Bifoga **Min karta-utskrift** + ev. Johans handskiss.  
- Eller **spara utkast** och komplettera när handläggaren frågar (BYGG 02).

Ändrad användning **utan** tillbyggnad: kommunen vill främst se **vilken byggnad** det gäller — inte den färdiga arrendegränsen.

---

## Vad ni *inte* behöver nu

- Ny mätning hos Lantmäteriet (ingen fastighetsbildning — Modell A).  
- Professionell arkitektritning.  
- Exakt m² i avtalet innan remsan är mätt.
